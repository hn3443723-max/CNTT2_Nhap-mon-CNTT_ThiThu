# Website Cửa Hàng Văn Phòng Phẩm

Đây là **hệ thống quản lý** và *phát triển website* thương mại điện tử chuyên cung cấp các dụng cụ, thiết bị văn phòng phẩm trực tuyến.

## Bảng cấu trúc thư mục

| Thư mục / File | Nội dung mô tả |
| :--- | :--- |
| `docs/` | Chứa tài liệu nghiệp vụ, đơn hàng nhập kho (`nhap_hang.txt`) |
| `data/` | Chứa dữ liệu bảng tính hệ thống bán hàng (`don_ban_thang_10.xlsx`) |
| `logs/` | Lưu trữ file log hệ thống và báo cáo lỗi tự động |
